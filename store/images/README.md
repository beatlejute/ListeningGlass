# Материалы карточки Chrome Web Store

Требуемые размеры записаны в `store/listing.md` («small promo tile 440×280, screenshots 1280×800»);
магазин принимает от 1 до 5 скриншотов. Столбец «Измерено» — размер из заголовка IHDR самого PNG;
его сверяет тест `test/store-images.test.mjs` (`npm test`), поэтому таблица не расходится с файлами.

| Файл | Требуется | Измерено | Роль |
|------|-----------|----------|------|
| `promo-440x280.png` | 440×280 | 440×280 | промо-плитка карточки |
| `screenshot-1.png` | 1280×800 | 1280×800 | панель: сайт включён |
| `screenshot-2.png` | 1280×800 | 1280×800 | панель: свой сайт добавлен |
| `screenshot-3.png` | 1280×800 | 1280×800 | панель: сайт выключен, подсказка о перезагрузке |
| `screenshot-4.png` | 1280×800 | 1280×800 | плеер играет при свёрнутом браузере |
| `screenshot-5.png` | 1280×800 | 1280×800 | системные медиаконтролы ОС |

Скриншоты сняты без полей: канвас сцены ровно 1280×800, `deviceScaleFactor: 1`, снимок по `clip`
без отступов. На изображениях нет чужих логотипов и названий сервисов: единственный рисунок —
иконка расширения `src/icons/icon-128.png`, хосты взяты из зарезервированных доменов
`media.example.com` и `player.example.org`, плейлист назван нейтрально.

`icon-source.png` (1254×1254) лежит в этом каталоге, но материалом карточки не является: это
исходный рисунок, из которого нарезаны иконки расширения. В магазин он не загружается, требования
к промо-плитке и скриншотам к нему не относятся.
